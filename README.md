# Sola · FastFlag Studio

Sola is a Windows desktop app for organizing Roblox FastFlag profiles. This repository documents the v1.0.17 beta. It currently contains the project README only.

## Working with profiles

- Import a JSON profile to review flag names, types, and values. If entries disagree on a value, Sola identifies the conflicting flag so you can correct the file.
- Open **Presets** and choose **Offense** to load an editable copy of the 206-flag profile. You can save your changes as a personal preset or export them to JSON. The built-in preset stays available for reuse.
- Open **Activity → Read usage log** and press **Ctrl+F** to find a flag by name. **Find next** highlights the next match.
